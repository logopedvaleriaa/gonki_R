# Гоночный кубок

Локальная браузерная 3D-гонка для логопедических занятий: кольцевой автодром, спортивный автомобиль, два соперника и игровые пит-стопы с картинками на твёрдый Р. Русский интерфейс, управление мышью, клавиатурой и касанием. Никаких аккаунтов, платежей или внешних ресурсов во время игры.

## Локальный запуск

Нужен Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Открыть http://localhost:5187/. Если порт занят, сервер, возможно, уже запущен — сначала откройте ссылку. Для планшета в той же Wi-Fi сети используйте адрес Network из терминала. Не открывайте index.html через file://.

```sh
npm run build
npm run preview
```

Готовая статическая сборка — `dist/`. Все библиотеки входят в сборку. Модели и текстуры автодрома создаются локально; предметные акварельные картинки включены в проект. Нужен WebGL. Звук двигателя включается после действия пользователя и отключается верхней кнопкой звука.

## Как играть

1. Выберите машину, цвет и имя гонщика.
2. Перед гонкой можно выполнить артикуляционную гимнастику. Её таймер автоматически начинает отсчёт с 10 секунд; длительность можно изменить. Переход между упражнениями ручной.
3. Нажмите ↑ или W (либо «Начать гонку»), дождитесь отсчёта 3–2–1. Пройдите два круга, обгоняя двух соперников.
4. Стрелки влево/вправо или A/D — руль. Вверх/W — газ, вниз/S — тормоз. Экранные стрелки работают щелчками; «Тормоз» переключает торможение, Тормоз полностью останавливает машину. Для разгона удерживайте ↑ / W или экранную кнопку «Газ». При отпускании машина замедляется по инерции.
5. По пути автоматически открываются восемь полноценных игр: Мемори, «Найди часть», «Четвёртый лишний», крестики-нолики, «Найди тень», «Запомни картинки», «Что пропало?» и «Доббль». Первая встречается примерно через 7–12 секунд езды. Автомобили и время останавливаются; после завершения игры ребёнок возвращается на то же место и сам продолжает гонку нажатием ↑ или W. Дополнительных речевых карточек на дороге нет.
6. После двух гоночных кругов начинается свободный третий круг без заданий. Через небольшой участок пути появляются два новых соперника для дополнительной погони. После него показываются место, очки и монеты. Можно начать ещё одну гонку или вернуться в меню.

Пробел, Escape и кнопка паузы приостанавливают заезд. Потеря фокуса также включает паузу. Контакт и выезд на обочину замедляют машину. После перезагрузки сохранённый заезд продолжается с последней записанной точки.

В гараже можно изменить цвет и купить украшения за игровые монеты. Они открываются по рекорду за гонку. Основной заезд проходит по кольцевому автодрому с восемью игровыми остановками.

## Логопеду

В речевом банке 17 проверенных слов с твёрдым Р и 8 словосочетаний, без мягкого Рь. Все предметные изображения — локальные книжные акварельные иллюстрации. В настройках можно выбрать слова/словосочетания, подписи, группу, свой список из готового словаря, сложность и включение речевых заданий. Выбранный материал используется в следующих заданиях. Переключение слов/словосочетаний внутри мини-игры запускает её заново.

Произношение игра автоматически не оценивает. Речь отрабатывается внутри мини-игр: ребёнок называет акварельные картинки и повторяет слова. Отдельного подтверждения произношения в Мемори и дуэли нет. Выполненные задания добавляют очки к гоночному результату.

Артикуляционная гимнастика — 16 упражнений, выбор и избранное, свой текст подсказок и таймер. Оформление кремово-персиковое. Её можно отключить в настройках или пропустить.

Старые мини-игры доступны отдельно в меню «Мини-игры»: Мемори, дуэль, сборка, заправка и другие. Восемь из них также являются этапами основного заезда. Мемори — 2 раунда на 5 и 10 пар, без речевых подтверждений. Дуэль — три раунда с прямыми ходами без окон передачи хода. «Запомни картинки» — акварельные слова на твёрдый Р, последовательности из 3–5 картинок.

Для Zoom покажите окно игры и передайте ученику удалённое управление. В основной гонке управляет только ребёнок; отдельного сетевого подключения двух браузеров нет. Ученик и логопед могут играть друг против друга в отдельной дуэли.

Прогресс, рекорд, награды и настройки сохраняются в localStorage данного браузера и адреса. Старые награды не удаляются при переходе к новому гоночному режиму. Сброс прогресса требует подтверждения.

Подробнее: [игровой цикл](docs/game-flow.md), [речевой материал](docs/speech-material.md), [гимнастика](docs/warmup.md).

## Проверки

```sh
npx playwright install chromium
npm run dev
# В другом терминале:
npm test
```

Браузерные тесты проверяют управление, остановки с играми, сохранение, итоговое место и награды. Отчёт о проверке: [docs/verification.md](docs/verification.md). Для WebKit используйте `PW_BROWSER=webkit npm test`; при нестандартной установке браузера можно задать `PW_EXECUTABLE_PATH`. Снимки экрана — `test-results/`. Сценарии предыдущего лабиринта запускаются отдельно с сохранённым режимом `adventureView: "maze"`.

## Структура

- `src/main.js` — игровые состояния, управление, пит-стопы, настройки, сохранения.
- `src/circuit-world.js` — кольцевая трасса, спортивные автомобили, материалы, камера.
- `src/world.js` — общий Three.js renderer и сцены.
- `src/speech.js`, `src/memory.js`, `src/warmup.js` — речевой банк, Мемори, гимнастика.
- `src/style.css` — интерфейс и адаптивное оформление.
- `public/images/` — локальные акварельные картинки.
- `tests/grand-prix.spec.js` — проверки основного заезда.
- `src/labyrinth.js`, `src/journey.js` — предыдущие варианты приключения.

## GitHub Pages

Проект не опубликован. Для будущей публикации выполните `npm run build` и разместите содержимое `dist/` на GitHub Pages. Сборка использует относительные пути и работает в подпапке репозитория. Серверная часть не нужна. Публикация выполняется только по отдельной просьбе.

Добавлены две игры: «Четвёртый лишний» — 10 раундов, поиск лишнего среди 6–12 перемешанных предметов; «Что пропало?» — 3 раунда, по три картинки для запоминания. Обе доступны на трассе и в меню мини-игр. В гонке теперь 8 игровых остановок. Ошибки допускают повтор без штрафа. Используется акварельная коллекция твёрдого Р.

Ограждения — сплошные изогнутые панели, повторяющие трассу на расстоянии 8,5 м от оси дороги. Длинные прямые секции, которые выступали в поворотах, заменены общей геометрией без разрывов. Ручное управление газом сохранено.

Перед игровой остановкой (за 150 м) появляется синий знак с флажком, названием мини-игры и расстоянием. Бордюры построены единой геометрией без наложений; настроены зазоры разметки, фильтрация текстур, глубина камеры и стабилизация теней.

Усложнение: «Найди часть» — 8 раундов, 6 вариантов с похожими предметами, небольшой увеличенный фрагмент без пустых белых участков. Фрагмент уменьшается по мере прохождения. «Четвёртый лишний» — 10 раундов по 6–12 предметов в ровной сетке без пустых ячеек. Лишний предмет меняет позицию в каждом раунде; подсказок о категории нет.

В крестиках-ноликах используются знаки × и ○ в углу клетки. Картинка после хода сохраняется; выигрышная линия выделяется рамками.

После двух основных кругов и всех восьми игр начинается дополнительный свободный круг: без заданий и указателей. Через 90–180 м впереди появляются два новых соперника: их можно догнать и обогнать. Газ остаётся ручным. Место основной гонки фиксируется до свободного круга, поэтому спокойная поездка не ухудшает результат. Итоговый экран и награда появляются после третьего круга. Свободный круг сохраняется при перезагрузке.

Темп соперников подстраивается под недавнюю скорость продвижения ученика. Если они сильно оторвались, плавно замедляются; если отстали, стараются догнать. Обгоны и место зависят от фактически пройденной дистанции: разгон помогает выйти вперёд, торможение, заносы и обочина позволяют соперникам отыграться. В облегчённом режиме их темп ниже. На паузе и во время мини-игр все машины останавливаются.

«Доббль» — 10 раундов: найдите и назовите единственный общий предмет на двух круглых карточках. Можно нажать на него на любой карточке. В обычном режиме число картинок растёт с 4 до 6, в облегчённом — с 3 до 5. Размер и положение меняются, совпадение всегда одно. Поддерживаются слова/словосочетания, подписи, мышь, касание и клавиатура; таймера и дополнительных подтверждений нет. Используется та же локальная акварельная коллекция на твёрдый Р. Игра доступна в меню и последней остановкой основного заезда; уже начатый до обновления свободный круг продолжается без новых остановок.

Погоня на третьем круге: красная машина №58 и бирюзовая №74 появляются впереди, не перекрывая путь. Их темп подстраивается под ученика. В блоке «Погоня» показано текущее место, на мини-карте — новые машины. Пауза и сохранение действуют для всех машин; газ остаётся ручным. Положение в погоне показывается отдельно на финальном экране, основное место и награда не меняются. Новых заданий или подтверждений на третьем круге нет.
