## Результаты

- Chromium: подтверждены все 68 сценариев проверявшегося набора. Полный запуск проверил 67 сценариев; после исправления устаревшего ожидания числа игр и перезапуска прерванного обновлением Vite сценария интерфейс и гимнастика повторно прошли все 8 проверок. ## Повторный запуск

```sh
npm run dev
# В другом терминале:
npm run build
npm test
```

Для WebKit после установки соответствующего браузера Playwright:

```sh
PW_BROWSER=webkit npm test
```

Во время проверки не редактируйте исходники: Vite может перезагрузить открытое окно теста. Проверки не заменяют занятия на каждом реальном устройстве; физические iPhone/iPad и передача управления через Zoom отдельно не тестировались. Проект не опубликован.
